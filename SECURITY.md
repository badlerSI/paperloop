# Security

Please report a security problem privately, through **Report a vulnerability** on the repository's
[Security tab](https://github.com/badlerSI/paperloop/security), not in a public issue.

Worth reporting:
- anything that could send student work, a name, or a teacher's details anywhere other than the teacher's
  own Claude workspace;
- text on a scanned page, a reading, or an input file that could make Claude or the scripts act against
  the skill's privacy rules;
- a crafted input file that makes the scripts read or write outside the folders they're given.

Fixes go out as a new plugin version and a new release of the skill zip.
